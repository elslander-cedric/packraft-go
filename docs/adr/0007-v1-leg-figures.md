# 7. v1 leg figures: distance, elevation, time

Date: 2026-10-10

## Status
Accepted

## Context
River-specific data (difficulty grade, water level, weirs, rapids) is patchy and hard to source. Basic figures are reliable and already useful.

## Decision
Each leg shows distance, elevation gain/loss and estimated time; the trip shows totals. River information is deferred to v2.

## Consequences
- Requires an elevation data source and a time-estimation rule per mode.
