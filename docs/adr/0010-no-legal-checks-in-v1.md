# 10. No river-access rule checking in v1

Date: 2026-10-10

## Status
Accepted

## Context
Many Walloon rivers restrict kayaking by season, water level or stretch. Encoding these rules is work and must be kept up to date.

## Decision
v1 does not check navigation rules. The app shows a visible notice that the user must check local navigation rules. Real access data is a v2 candidate.

## Consequences
- Revisit before the app is shared beyond a small circle.
