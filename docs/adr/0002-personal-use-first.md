# 2. Personal use first, no accounts

Date: 2026-10-10

## Status
Accepted

## Context
Accounts, privacy and hosting a multi-user service are a large chunk of work that delays a usable app.

## Decision
v1 is built for Cedric (and a few friends). There are no sign-ups or user accounts.

## Consequences
- Much faster to a working app.
- Keep data handling simple enough that accounts could be added later without a rewrite.
