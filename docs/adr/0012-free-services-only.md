# 12. Free services only

Date: 2026-10-10

## Status
Accepted

## Context
This is a personal learning project with no budget.

## Decision
v1 uses only free services: no paid tiers, no payment method on file. If a free limit becomes a problem, Cedric decides before anything is spent.

## Consequences
- Prefer services without API keys, since keys in a static site are public anyway.
