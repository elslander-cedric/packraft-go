# 0. Record architecture decisions

Date: 2026-10-10

## Status
Accepted

## Context
We need a lightweight way to remember why decisions were made, so future contributors (human or AI) don't re-litigate them.

## Decision
We record significant decisions as short Markdown ADRs in `docs/adr/`, numbered sequentially.

## Consequences
Each ADR captures context, decision and consequences. Superseded ADRs are kept and marked as such.
